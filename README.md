## Возможности

- Загрузка PNG, JPG/JPEG и GB7.
- Отрисовка изображения на `<canvas>`.
- Скачивание результата в PNG, JPG/JPEG и GB7.
- Нижняя строка состояния с исходной шириной, высотой и глубиной цвета.
- Собственный кодер и декодер GrayBit-7 по спецификации курса.
- Поддержка маски GB7 через старший бит пикселя.
- Просмотр RGB/A-каналов, коррекция уровней, гистограммы и пипетка.
- Собственная интерполяция ближайшим соседом и билинейная интерполяция.
- Масштаб просмотра от 12% до 300% с автоподгонкой изображения при загрузке.
- Инструмент изменения размера изображения с выбором единиц, сохранением пропорций и алгоритмом интерполяции.
- Фильтрация 3×3 kernel: резкость, Гаусс, box blur, Прюитт X/Y и пользовательское ядро.
- Предпросмотр kernel-фильтра, выбор каналов и стратегия обработки краев.

## Интерполяция

Реализация находится в `src/utils/interpolation.ts`.

Доступные методы:

- `nearest` - метод ближайшего соседа;
- `bilinear` - билинейная интерполяция, используется по умолчанию.

Эти методы используются при масштабировании изображения на главном canvas и при изменении реального размера изображения.

## Проверка

```bash
npm run build
npm run lint
```

Ручной чеклист:

- открыть PNG, JPG/JPEG и GB7;
- проверить масштаб просмотра 12%, 100%, 300% и автоподгонку при открытии большого изображения;
- проверить resize в процентах и пикселях, с сохранением и без сохранения пропорций;
- проверить оба метода интерполяции на resize и отображении;
- проверить kernel-фильтры: identity, sharpen, gaussian, box blur, Prewitt X/Y;
- проверить применение kernel-фильтра к одному и нескольким каналам;
- проверить стратегии края: черный, белый, копирование;
- проверить экспорт PNG, JPG/JPEG и GB7 после изменения размера.
